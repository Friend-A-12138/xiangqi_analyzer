# 中国象棋AI分析器 - 项目总览

## 📋 项目简介

基于 ONNX 深度学习模型与 Pikafish 引擎的中国象棋分析系统：
图片/视频流/模拟器/屏幕 → 棋盘检测与棋子识别 → FEN → 引擎推荐 → 中文记谱与箭头，
并提供 Web 界面、批量分析、用户管理与内网穿透。

## 🏗️ 系统架构

```text
┌──────────────────────────────────────────────────────────────┐
│ Web 层（Flask + SocketIO）                                     │
│  登录 / 首页 / 设置 / 上传 / 批量 / 实时预览 / 用户 / 隧道      │
└───────────────────────────┬──────────────────────────────────┘
                            │ JSON / WebSocket
┌───────────────────────────▼──────────────────────────────────┐
│ 应用服务层                                                     │
│  config 配置中心（config.json + 环境校验 + CLI 合并）           │
│  XiangqiAnalyzer：检测 → FEN → 引擎 → 中文记谱/箭头            │
└───────────────┬───────────────────────────┬──────────────────┘
                │                           │
┌───────────────▼─────────────┐ ┌───────────▼──────────────────┐
│ 检测器（CCR 子模块）          │ │ Pikafish 引擎（UCI）          │
│  onnx_runtime 注入 provider  │ │  Threads/Hash 启动时下发      │
│  CUDA → CPU 自动回退         │ │  崩溃自动重启                 │
└───────────────┬─────────────┘ └──────────────────────────────┘
                │
┌───────────────▼──────────────────────────────────────────────┐
│ 输入层：图片 / RTMP-RTSP / 模拟器截图 / 屏幕区域                │
│ 帧差分：画面无变化时跳过检测与引擎                              │
└──────────────────────────────────────────────────────────────┘
```

## 🎯 核心能力

| 能力 | 实现位置 | 说明 |
|---|---|---|
| 棋盘检测与识别 | `CCR` 子模块 + `src/chess_analyzer.py` | 透视校正 + 10×9 棋子分类 |
| GPU 加速 | `src/onnx_runtime.py` | provider 可配，不可用自动回退 CPU |
| FEN 生成 | `src/chess_analyzer.py` | 按红帅位置统一朝向，遮挡 `x` 按空位处理 |
| 中文记谱 | `src/xiangqi_notation.py` | 红中/黑阿，进退平，同列 2-5 子 |
| 走法箭头 | `src/board_render.py` | 棋盘比例固定箭头，可投影回原图 |
| 显示朝向 | `src/board_view.py` | 执红红在下、执黑黑在下，坐标同步旋转 |
| 引擎交互 | `src/chess_analyzer.py` | UCI、Threads/Hash、走子方、崩溃重启 |
| 帧差分 | `src/frame_diff.py` | 灰度均方差阈值，跳过无变化画面 |
| Web 与实时推送 | `web/app.py` | Flask + SocketIO，含批量与用户管理 |
| 内网穿透 | `src/tunnel_service.py` | ngrok / frp，Web 启停 |

## 📊 数据流

**单图分析**：上传 → 解码 → 检测（GPU/CPU）→ FEN → 引擎搜索 → 中文记谱/箭头 → JSON（含图像 base64）。

**实时分析**：采集帧 → 帧差分 → 检测 → 引擎 → SocketIO 推送文本结果；预览帧服务端叠加箭头。

## 🧪 验证与性能（本机实测）

| 项目 | 结果 |

## 🛡️ 安全与配置

- 用户密码 PBKDF2-SHA256 加盐存储（`config/users.json`，已 gitignore）；
- 配置与用户文件均在本地，检测与引擎不联网；
- 内网穿透为可选能力，默认关闭；启用后等于把 Web 暴露到公网，请自行评估风险。
